ПРОБЛЕМА:
---------
Лидерборд очищается при каждом перезапуске бота на Render.com
Результаты игроков исчезают, хотя ничего не делали.

ПРИЧИНА:
--------
Render.com бесплатный план НЕ сохраняет файлы!
Файл leaderboard.json удаляется при перезапуске (каждые 15 минут).

РЕШЕНИЕ:
--------
MongoDB Atlas - бесплатная облачная база данных.
Данные сохраняются навсегда, не удаляются при перезапуске.

═══════════════════════════════════════════════════════════
  КАК РАБОТАЕТ
═══════════════════════════════════════════════════════════

БЕЗ MongoDB:
------------
1. Игрок отправляет результат
2. Сохраняется в leaderboard.json
3. Render перезапускается
4. ❌ Файл удаляется
5. ❌ Результаты потеряны

С MongoDB:
----------
1. Игрок отправляет результат
2. Сохраняется в MongoDB Atlas (облако)
3. Render перезапускается
4. ✅ Данные в облаке остаются
5. ✅ Результаты сохранены навсегда!

═══════════════════════════════════════════════════════════
  ТЕХНИЧЕСКИЕ ДЕТАЛИ
═══════════════════════════════════════════════════════════

База данных: typecat
Коллекция: leaderboard

Структура документа:
{
  "name": "Игрок",
  "clicks": 12345,
  "hats": 15,
  "date": "2026-05-01T12:00:00.000Z",
  "timestamp": "2026-05-01T12:00:00.000Z"
}

Переменная окружения:
MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/...

Fallback:
Если MONGODB_URI не задан, используются файлы (для локального теста).
