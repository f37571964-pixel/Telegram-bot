# Быстрая настройка бота

## Шаг 1: Узнайте свой Telegram ID

1. Откройте Telegram
2. Найдите бота @userinfobot
3. Напишите ему `/start`
4. Он пришлёт ваш ID (например: 123456789)

## Шаг 2: Настройте бота

1. Откройте файл `bot.js`
2. Найдите строку:
   ```javascript
   const ADMIN_ID = 'YOUR_TELEGRAM_ID';
   ```
3. Замените `YOUR_TELEGRAM_ID` на ваш ID:
   ```javascript
   const ADMIN_ID = '123456789';
   ```
4. Сохраните файл

## Шаг 3: Запустите бота

### Windows:
Просто запустите `start-bot.bat`

### Или вручную:
```bash
npm install
npm start
```

## Шаг 4: Проверьте работу

1. Найдите вашего бота в Telegram (имя бота можно узнать у @BotFather)
2. Напишите `/start`
3. Если всё работает - увидите меню команд

## Команды бота:

- `/start` - Показать список команд
- `/version` - Показать текущую версию
- `/update` - Опубликовать новое обновление
- `/changelog` - Показать список изменений

## Публикация обновления:

1. Напишите `/update`
2. Отправьте данные в формате:
```
1.0.3
Новые фичи и улучшения
https://www.mediafire.com/file/ссылка-на-файл.exe
- 🎨 Новый дизайн
- 🐛 Исправлены баги
- ⚡ Улучшена производительность
```

3. Бот сохранит информацию
4. Пользователи получат уведомление при запуске TypeCat

## Важно!

После публикации обновления нужно:
1. Загрузить файл `version.json` на сервер
2. Или использовать GitHub Pages / Vercel для хостинга

Файл `version.json` должен быть доступен по URL, который указан в `update-checker.js`
