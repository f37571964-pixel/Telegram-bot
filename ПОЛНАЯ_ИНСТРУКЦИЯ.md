# 🚀 Полная инструкция по настройке автообновлений

## ✅ Что уже сделано:

1. ✅ Бот принимает .exe файлы через команду `/upload`
2. ✅ Бот раздаёт файл через `/download` endpoint
3. ✅ Лаунчер скачивает и устанавливает обновления
4. ✅ MongoDB настроен для лидерборда
5. ✅ `version.json` обновлён на правильный URL

## 📋 Что нужно сделать:

### Шаг 1: Загрузить изменения на GitHub

Изменения уже закоммичены, нужно только запушить:

```bash
cd telegram-bot
git push --set-upstream origin main
```

**Если ошибка 403 (Permission denied):**

Вариант А - Через GitHub Desktop:
1. Откройте GitHub Desktop
2. Выберите репозиторий `Telegram-bot`
3. Нажмите "Push origin"

Вариант Б - Через токен:
1. Создайте Personal Access Token на GitHub:
   - https://github.com/settings/tokens
   - Generate new token (classic)
   - Выберите `repo` scope
2. Используйте токен вместо пароля при push

Вариант В - Через upload-to-github.bat:
```bash
cd telegram-bot
./upload-to-github.bat
```

### Шаг 2: Дождаться деплоя на Render.com

После push на GitHub:
1. Зайдите на https://render.com
2. Откройте ваш сервис `telegram-bot`
3. Дождитесь автоматического деплоя (2-3 минуты)
4. Проверьте что бот запустился без ошибок

### Шаг 3: Загрузить установщик в бота

1. Соберите установщик TypeCat 1.0.4:
   ```bash
   # Используйте Inno Setup или build-portable.bat
   ```

2. Откройте бота в Telegram

3. Отправьте команду `/upload`

4. Отправьте .exe файл боту

5. Дождитесь подтверждения:
   ```
   ✅ Установщик загружен!
   📦 Файл: TypeCat-Setup-1.0.4.exe
   ```

### Шаг 4: Проверить что всё работает

1. Откройте в браузере:
   ```
   https://telegram-bot-zw0g.onrender.com/download
   ```
   Должно начаться скачивание .exe файла

2. Запустите лаунчер TypeCat

3. Проверьте что он видит версию 1.0.4

4. Нажмите кнопку обновления

5. Проверьте что скачивание работает

## 🎯 Итоговая схема работы:

```
1. Вы собираете новый TypeCat-Setup.exe
   ↓
2. Отправляете файл боту через /upload
   ↓
3. Бот сохраняет файл на Render.com
   ↓
4. Лаунчер проверяет версию через API

```

## ❓ Частые проблемы:

**Бот не запускается на Render:**
- Проверьте что MongoDB URI настроен в Environment Variables
- Проверьте логи деплоя

**Файл не скачивается:**
- Убедитесь что вы загрузили файл через `/upload`
- Проверьте что бот запущен

**Лаунчер не видит обновление:**
- Проверьте что `version.json` содержит правильный URL
- Откройте https://telegram-bot-zw0g.onrender.com/version в браузере

**Git push не работает:**
- Используйте GitHub Desktop
- Или создайте Personal Access Token
