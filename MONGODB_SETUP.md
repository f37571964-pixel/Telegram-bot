# 🗄️ Настройка MongoDB Atlas для TypeCat Bot

## ⚠️ ВАЖНО: Почему нужна MongoDB?

**Render.com бесплатный тариф НЕ сохраняет файлы при перезапуске!**

Это значит что `leaderboard.json` удаляется каждый раз когда:
- Сервер перезапускается (каждые 15 минут неактивности)
- Вы делаете новый деплой
- Render перезапускает сервис

**MongoDB Atlas** - это бесплатная облачная база данных, которая сохраняет данные навсегда!

---

## 📋 Шаг 1: Создать аккаунт MongoDB Atlas

1. Перейди на https://www.mongodb.com/cloud/atlas/register
2. Зарегистрируйся (можно через Google)
3. Выбери **FREE** план (M0 Sandbox)
4. Выбери регион ближайший к тебе (например, Frankfurt для Европы)
5. Назови кластер `TypeCat` (или любое имя)
6. Нажми **Create Cluster**

---

## 📋 Шаг 2: Настроить доступ к базе данных

### 2.1 Создать пользователя базы данных

1. В левом меню выбери **Database Access**
2. Нажми **Add New Database User**
3. Выбери **Password** authentication
4. Введи:
   - Username: `typecat_bot`
   - Password: **Создай сложный пароль** (сохрани его!)
5. Database User Privileges: **Read and write to any database**
6. Нажми **Add User**

### 2.2 Разрешить доступ с любого IP

1. В левом меню выбери **Network Access**
2. Нажми **Add IP Address**
3. Нажми **Allow Access from Anywhere** (0.0.0.0/0)
4. Нажми **Confirm**

⚠️ Это безопасно, потому что доступ защищен паролем!

---

## 📋 Шаг 3: Получить строку подключения (Connection String)

1. В левом меню выбери **Database**
2. Найди свой кластер и нажми **Connect**
3. Выбери **Drivers**
4. Выбери **Node.js** и версию **6.0 or later**
5. Скопируй строку подключения, она выглядит так:

```
mongodb+srv://typecat_bot:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
```

6. **ЗАМЕНИ** `<password>` на пароль который ты создал в шаге 2.1

Пример готовой строки:
```
mongodb+srv://typecat_bot:MySecretPass123@cluster0.abc12.mongodb.net/?retryWrites=true&w=majority
```

---

## 📋 Шаг 4: Добавить MONGODB_URI на Render.com

1. Перейди на https://dashboard.render.com
2. Открой свой сервис **telegram-bot**
3. Перейди в **Environment**
4. Нажми **Add Environment Variable**
5. Добавь:
   - **Key:** `MONGODB_URI`
   - **Value:** твоя строка подключения из шага 3
6. Нажми **Save Changes**

Render автоматически перезапустит бота с новой переменной!

---

## ✅ Шаг 5: Проверить что всё работает

1. Подожди 1-2 минуты пока бот перезапустится
2. Открой логи на Render (вкладка **Logs**)
3. Ты должен увидеть:
   ```
   ✅ MongoDB подключен!
   🤖 TypeCat Update Bot запущен!
   ```

4. Если видишь ошибку:
   ```
   ❌ Ошибка подключения к MongoDB: ...
   ```
   - Проверь что пароль правильный (без `<` и `>`)
   - Проверь что IP адрес 0.0.0.0/0 добавлен в Network Access
   - Проверь что пользователь создан в Database Access

---

## 🎮 Проверка работы лидерборда

1. Открой TypeCat приложение
2. Сыграй и отправь результат в лидерборд
3. Перейди на https://telegram-bot-zw0g.onrender.com/leaderboard
4. Ты должен увидеть свой результат в JSON формате

5. Теперь перезапусти бот на Render:
   - Перейди в **Manual Deploy** → **Clear build cache & deploy**
   
6. После перезапуска снова открой https://telegram-bot-zw0g.onrender.com/leaderboard
7. **Твой результат всё ещё там!** 🎉

## 📊 Просмотр данных в MongoDB Atlas

1. Перейди на https://cloud.mongodb.com
2. Выбери **Database** → **Browse Collections**
3. Ты увидишь базу данных `typecat`
4. Внутри коллекция `leaderboard` со всеми результатами!

Можешь вручную редактировать, удалять или добавлять записи.

## ❓ Частые вопросы

**Q: Сколько стоит MongoDB Atlas?**
A: FREE план (M0) бесплатный навсегда! 512 MB хранилища (хватит на миллионы результатов)

**Q: Что если я превышу лимит?**
A: 512 MB = примерно 500,000 результатов лидерборда. Если превысишь, можно очистить старые записи.

**Q: Можно ли использовать другую базу данных?**
A: Да, можно PostgreSQL, MySQL и т.д., но MongoDB проще всего настроить бесплатно.

**Q: Что если не настрою MongoDB?**
A: Бот будет работать, но лидерборд будет очищаться при каждом перезапуске Render.
