# 🏆 Лидерборд TypeCat

## Как работает

Лидерборд подключен к Telegram боту и работает через API.

## Запуск

1. **Установите зависимости** (если ещё не установлены):
   ```bash
   cd telegram-bot
   npm install
   ```

2. **Запустите бота**:
   ```bash
   npm start
   ```
   Или просто запустите `start-bot.bat`

3. **Сервер запустится на порту 3000**:
   - API лидерборда: `http://localhost:3000/leaderboard`
   - Отправка результата: `http://localhost:3000/leaderboard/submit`

## Команды бота

В Telegram напишите боту:

- `/leaderboard` - Показать топ-10 игроков
- `/stats` - Статистика лидерборда
- `/clearleaderboard` - Очистить лидерборд

## Как использовать в приложении

1. Запустите бота (см. выше)
2. Откройте TypeCat
3. Меню → 🏆 Лидерборд
4. Нажмите "📤 Отправить результат"
5. Введите имя
6. Готово! Ваш результат в глобальном лидерборде

## Файлы

- `leaderboard.json` - хранит все результаты (создаётся автоматически)
- Хранит до 1000 лучших результатов
- Автоматически сортируется по кликам

## API Endpoints

### GET /leaderboard
Получить топ-100 игроков

**Ответ:**
```json
[
  {
    "name": "Player1",
    "clicks": 50000,
    "hats": 15,
    "date": "2026-05-01T12:00:00.000Z"
  }
]
```

### POST /leaderboard/submit
Отправить результат

**Запрос:**
```json
{
  "name": "Player1",
  "clicks": 50000,
  "hats": 15
}
```

**Ответ:**
```json
{
  "success": true,
  "rank": 5,
  "message": "Вы на 5 месте!"
}
```

## Для продакшена

Чтобы использовать на реальном сервере:

1. Разместите бота на хостинге (Render.com, Heroku, VPS)
2. В `script.js` замените:
   ```javascript
   const LEADERBOARD_API = 'https://ваш-домен.com/leaderboard';
   ```
3. В функции `submitScore()` замените URL на:
   ```javascript
   fetch('https://ваш-домен.com/leaderboard/submit', ...)
   ```

## Проблемы?

### Ошибка "Cannot find module 'express'"
```bash
cd telegram-bot
npm install express cors
```

### Лидерборд не загружается
- Проверьте что бот запущен
- Проверьте консоль браузера (F12)
- Убедитесь что порт 3000 свободен

### Результат не отправляется
- Запустите бота
- Проверьте что сервер работает: откройте `http://localhost:3000/leaderboard` в браузере
